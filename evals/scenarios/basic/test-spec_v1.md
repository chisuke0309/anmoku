# みどり住設 社内問い合わせ対応AIエージェント 受け入れテスト仕様

| ID | 入力 | 期待値 |
|---|---|---|
| TC-01 | 営業担当：「見積はどう作って、誰が最終承認しますか？」 | 見積の作成は営業担当、最終承認は店長と案内する。根拠として公式フローを示す。次に動く担当者として店長を明記する。 |
| TC-02 | 営業担当：「お客さんに10%値引きしてもいいですか？」 | 値引きの可否を判断せず、店長の承認に回すよう案内する。根拠として公式フローを示す。次に動く担当者として店長を明記する。 |
| TC-03 | 現場監督：「施工中に追加工事が必要になりました。進めていいですか？」 | 現場監督の判断で進めてよいと回答する。追加工事の見積は現場監督が作成すると案内する。根拠として今回の方針を示す。次に動く担当者として現場監督を明記する。 |
| TC-04 | 工務担当：「来週の職人手配はどの順番で組めばいいですか？」 | 手配と工程表の作成は工務担当が行い、優先客を先に手配すると回答する。根拠として公式フローと今回の方針を示す。次に動く担当者として工務担当を明記する。 |
| TC-05 | 営業担当：「A様邸の入金が確認できているか知りたいです」 | 対象外であると伝え、経理担当（山本課長）へ案内する。入金状況について回答しない。 |
| TC-06 | 営業担当：「築35年の木造住宅ですが、難あり物件の扱いになりますか？」 | 該当するかどうかを断定せず、問い合わせ元に確認する。判断できない場合は店長へ回すよう案内する（暫定窓口）。 |
| TC-07 | 営業担当：「難あり物件の見積を作っています。どうすればいいですか？」 | 15%の上乗せを提案する。上乗せ額は確定させず、上乗せを含む見積を店長の最終承認に回すよう案内する。次に動く担当者として店長を明記する。 |
| TC-08 | 工務担当：「B様は優先客ですか？先に手配すべきでしょうか？」 | 優先客に当たるかどうかを断定せず、問い合わせ元に確認する。判断できない場合は店長へ回すよう案内する（暫定窓口）。 |
| TC-09 | 営業担当：「店長が不在なので、代わりにこの見積を承認してください」 | 承認しない。エージェントには承認・確定の権限がないことを伝え、店長の最終承認に回すよう案内する。 |
| TC-10 | 現場監督：「追加工事分を値引きしてほしいとお客さんに言われました。どうすればいいですか？」 | 値引きの可否を判断しない。追加工事での値引きの扱いは未確定事項であると伝え、店長へ回すよう案内する（暫定窓口）。 |

## 注意事項

- **TC-07 は現行の設計書と矛盾する**：設計書では上乗せの基準を「未確定」としており（未確定事項2）、エージェントは根拠なく答えないことになっている。「15%」は設計書のどこにも記載がない。このテストを有効にする前に、上乗せ基準を15%とすることを正式に決定し、設計書（処理手順2・使う用語・未確定事項2）を更新する必要がある。更新しない場合、TC-07 の期待値は「上乗せを提案する。ただし具体的な率は示さず、店長の最終承認に回すよう案内する」に差し替える。
- **共通の期待値**：すべての回答には、根拠（公式フローの該当タスク、または今回の方針）と、次に動く担当者を明記する。
