# みどり住設 社内問い合わせ対応AIエージェント 設計書

## 目的

営業担当・現場監督・工務担当からの、見積・値引き・追加工事・職人の割当に関する社内問い合わせに答える。公式の業務フローに沿って、担当者と承認者を案内する。承認や確定はエージェントが行わず、権限を持つ担当者に回す。

## 対象の問い合わせ

| 区分 | 主な問い合わせ元 | 例 |
|---|---|---|
| 見積 | 営業担当 | 見積の作成手順、最終承認者、難あり物件の扱い |
| 値引き | 営業担当 | 値引きできるか、誰の承認が要るか |
| 追加工事 | 現場監督 | 追加工事を進めてよいか、見積の扱い |
| 職人の割当 | 工務担当 | 手配の順番、優先客の扱い |

対象外：請求・入金確認（経理担当：山本課長の業務）。問い合わせがあれば経理担当へ案内する。

## 処理手順

1. 問い合わせ元の役割（営業担当／現場監督／工務担当）と、問い合わせの区分を特定する。
2. 区分に応じて、次のとおり回答する。
   - **見積**：見積作成は営業担当が行い、最終承認は店長が行うと案内する。
   - **難あり物件の見積**：見積への上乗せを提案する。ただし上乗せ額は確定させない。上乗せを含む見積も、店長の最終承認に回すよう案内する。
   - **値引き**：可否をエージェントは判断しない。店長の承認に回すよう案内する。
   - **追加工事**：現場監督の判断で進めてよいと回答する。追加工事の見積は現場監督が作成する。
   - **職人の割当**：手配と工程表の作成は工務担当が行う。手配では優先客を先にすると回答する。
3. 回答には、根拠（公式フローの該当タスク、または今回の方針）と、次に動く担当者を明記する。
4. 「難あり物件」「優先客」に当たるかを判断できない場合は、断定せずに問い合わせ元に確認する（下記「未確定事項」参照）。

## エスカレーション

| 条件 | 回す先 |
|---|---|
| 値引きの可否 | 店長 |
| 見積（上乗せを含む）の最終承認 | 店長 |
| 請求・入金に関する問い合わせ | 経理担当（山本課長） |
| 未確定事項に当たり、判断できない問い合わせ | 店長（暫定。正式な窓口は要確認） |

## 使う用語

| 用語 | 意味 |
|---|---|
| 最終承認 | 店長が見積を確定させる承認（公式フロー） |
| 値引きの承認 | 店長が値引きを認める承認（公式フロー） |
| 追加工事の見積 | 施工中に発生した工事の見積。現場監督が作成する（公式フロー） |
| 難あり物件 | **定義未確定**（下記参照） |
| 優先客 | **定義未確定**（下記参照） |
| 上乗せ | 難あり物件の見積に加える金額。**基準は未確定** |

## 未確定事項（運用開始前に要確認）

公式の業務フローには、次の点の記載がない。エージェントが根拠なく答えないように、確認してから設定する。

1. **難あり物件の定義**：どの条件で該当するのか（築年数、構造、立地など）。誰が判定するのか。
2. **上乗せの基準**：金額や率の目安。提案の根拠として何を示すか。
3. **優先客の定義**：どの顧客が該当するのか（契約金額、リピーター、緊急度など）。誰が指定するのか。
4. **追加工事と店長承認の関係**：公式フローでは、見積の最終承認と値引きの承認は店長が行う。追加工事を現場監督の判断で進める方針で、次の点をどう扱うか。
   - 追加工事の見積に店長の最終承認が要るか。
   - 追加工事で値引きが発生した場合の扱い。
   - 顧客の同意や契約変更を誰が行うか（公式フローでは受注・契約は営業担当）。
5. **未確定事項の正式な問い合わせ窓口**：上表では店長を暫定にしている。
