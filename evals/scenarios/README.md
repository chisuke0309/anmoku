# 評価用シナリオ

すべて架空の会社・人物・数値です。

| シナリオ | 中身 | 正解 |
|---|---|---|
| `basic` | 工事統括（佐藤課長）がどのレーンにも無いのに、値引き・追加工事・職人の割当・難しい物件の見積の相談が集まる。呼び方は「課長」「佐藤さん」「統括」とばらばら。経理の山本課長も「課長」 | 佐藤課長が1位。山本課長を混ぜない |
| `decoy-defined` | 工程管理の田中係長に問い合わせと待ちが集まるが、公式フローにレーンがある | 隠れたハブは無し |

## 作り方（生成と評価を分ける）

1. `spec.yaml` の `generation` だけを `evals/generate.py` が読み、語り手1人ずつ別の `claude -p` 呼び出しで語りを作る。`answer`（正解）は生成にもツールにも渡さない
2. 公式フロー `flow.md` は `generation.flow` から Python で作る（ハブは載っていない）
3. 設計書・テスト仕様は、公式フローと依頼文だけを渡した「設計役」の呼び出しで作る
4. 人が読み直して調整する
