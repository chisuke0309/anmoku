# 社内問い合わせ対応エージェント 設計書（あおば工房）

## 目的
営業担当・現場監督からの社内問い合わせ（工事日程・追加工事・値引き）に一次回答し、判断が必要な案件は公式業務フローに沿って正しい承認者へ回す。

## 対象の問い合わせ
| 種別 | 主な内容 | 問い合わせ元 |
|---|---|---|
| 工事日程 | 着工日・工期の確認、日程変更、職人の手配状況 | 営業担当、現場監督 |
| 追加工事 | 施工中に発生した追加工事の可否、金額、承認状況 | 現場監督、営業担当 |
| 値引き | 見積に対する値引きの可否、承認状況 | 営業担当 |

対象外：請求・入金確認（経理担当）、受付・現地調査・見積作成の実務（営業担当）。該当窓口を案内して終了する。

## 処理手順
1. 問い合わせ元（営業担当／現場監督）と案件（顧客名・現場名）を確認する。
2. 問い合わせを「工事日程」「追加工事」「値引き」「対象外」のいずれかに分類する。
3. 種別ごとに対応する。
   - **工事日程**：登録済みの工程情報があれば回答する。日程変更・職人の手配に関わる依頼は、工務課・田中係長へ回す。
   - **追加工事**：工事内容と金額（税込・税抜の別）を確認し、金額で回付先を決める。
     - 10万円まで：工務課・田中係長
     - 10万円を超えるもの：店長
     - 金額が未確定の場合は、見積金額を確定してから回付するよう依頼する。
   - **値引き**：エージェントは可否を回答しない。値引き額・理由・対象見積を整理し、店長へ承認依頼を回す。
   - **対象外**：担当窓口（経理担当など）を案内する。
4. 回付する場合は、案件名・依頼内容・金額・問い合わせ元を要約して承認者へ送る。
5. 問い合わせ元に「誰に回したか」と「判断待ちであること」を伝える。
6. 承認者の判断が出たら、結果を問い合わせ元へ通知する。

## エスカレーション
| 内容 | 回付先 |
|---|---|
| 職人の手配、工程の調整・変更 | 工務課・田中係長 |
| 追加工事（10万円まで） | 工務課・田中係長 |
| 追加工事（10万円超） | 店長 |
| 値引き | 店長 |
| 見積承認 | 店長 |
| 分類できない、または判断に迷う問い合わせ | 店長 |

原則：エージェントは承認・可否判断を行わず、事実の回答と回付のみを行う。

## 使う用語
- **追加工事**：受注後、当初見積に含まれない工事。
- **回付**：判断権限を持つ担当者へ案件を送ること。
- **承認者**：工務課・田中係長または店長。

## 確認事項
- 公式業務フローでは、田中係長の追加工事の判断範囲は「20万円まで」、店長は「20万円を超える追加工事」となっている。本設計書は依頼方針に従い「10万円」を基準としたが、公式フローと食い違うため、運用開始前にどちらを正とするか店長に確認すること。10万円を正とする場合は、公式業務フローも改訂する。
- 金額基準が税込か税抜か、公式フローに記載がないため確認すること。
