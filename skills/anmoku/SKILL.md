# anmoku：定義されていない役割を見つける

業務改善の担当者が、ヒアリングの段階で「誰に仕事が集まっているのか」「その人の頭の中にしか無い判断基準は何か」を見つけ、
引き継げる形（定義台帳）にするための手順。**出力はすべて仮説**で、確かめるのは人が行う次のヒアリング。

## 前提

- 案件フォルダに `interviews/*.md`（1人1ファイル。ファイル名の順がヒアリングの順）と `flow.md`（Markdown表：| レーン | 担当 | タスク | 備考 |）がある
- 今ある定義台帳があれば `ledger/*.yaml`（1件1ファイル）に置く。承認済みの項目はそのまま物差しになり、語りから見つかった台帳に無いものが新しい候補として加わる
- `uv` と Claude Code（`claude` コマンド）が使える
- コマンドは `uv run --project "${CLAUDE_PLUGIN_ROOT}" anmoku <サブコマンド> <案件フォルダ>` で呼ぶ（以下 `anmoku` と略す）

## 手順

1. **ハブの検知**：`anmoku detect <案件>` を実行する。1人分ずつ別の文脈で語りを読み、引用を原文と照合し、呼び方をまとめ、Python で点数を付ける。
   - 結果の「ハブの仮説」を、点数の式と根拠の引用を添えて利用者に見せる。**次へ進む前に、候補が妥当かを利用者に確かめてもらう**
2. **定義台帳と質問**：`anmoku ledger <案件>`。回答待ちの用語・判断基準と、答えを持つ人への質問（優先順に5つ）を見せる
3. **フローの修正**：`anmoku fix <案件>`。修正役（flow-fixer：フローのファイルだけ書ける）が「仮」の行を足し、評価役（flow-evaluator：読み取り専用）が語りと照らして確認する。
   - 改善前後の違いと評価役の指摘を見せ、**利用者が承認したときだけ** `anmoku approve-flow <案件>` を実行する
4. **設計書の評価**（設計書があるとき）：`anmoku review <案件> <設計書.md> [--test <テスト仕様.md>]`。判定・重大な指摘・合格に残る条件（承認されていない定義）を見せる
5. **画面**：`<案件>/anmoku-out/index.html` を開くよう案内する（①ハブの発見 ②フローの修正と定義台帳 ③設計書の判定）

まとめて流すときは `anmoku run <案件> --design <設計書.md> --test <テスト仕様.md>`（フローの承認は別に行う）。
質問への答えは `anmoku answer <案件> <質問番号> "<答え>" --by <答えた人>` で記録する。
回答を確かめた定義は `anmoku approve <案件> <定義ID> "<定義>"` で承認済みにする。どちらも利用者の指示があるときだけ行う。

## 守ること

- 「ボトルネックの人」「責任者」のように人を評価する言い方をしない。「定義されていない役割」「判断が集まっている」と書き、結論は「役割を定義する・支える」方向にそろえる
- 点数・判定は Python が出したものをそのまま伝える。自分で点数を付け直したり、判定を言い換えたりしない
- フローのファイルを自分で直さない（修正役に任せる）。評価役に修正役の考えた経緯を渡さない
- 引用は原文と照合済みのものだけを使う。原文に無い言い方で根拠を作らない
- 承認（フロー・定義）は利用者が決める。自分で承認しない

## 役割（サブエージェント）

| 役割 | 権限 | 中身 |
|---|---|---|
| `narrative-extractor` | なし（語りは入力として渡す） | 1人分の語りから、引用つきの観察を取り出す |
| `alias-resolver` | なし | 呼び方を、観察ごとに同じ相手へまとめる提案 |
| `ledger-steward` | なし | 定義台帳の項目と質問の案 |
| `flow-fixer` | Read・Edit（Hook でフローのファイル以外は書けない） | 「仮」の行を足す |
| `flow-evaluator` | Read・Grep・Glob（Hook で書き込み禁止） | 修正版を語りと照らして確認 |
| `design-evaluator` | Read・Grep・Glob（Hook で書き込み禁止） | 設計書を物差しで評価 |

CLI は同じ指示文（`agents/*.md`）を `claude -p` に渡して動かす。会話の中で個別に確認したいときは、これらのサブエージェントを直接呼んでもよい。
