## 撮る前の準備

台本は、結果を固定した実行（`docs/demo/index.html`）に合わせて書いている。LLM を使うので、実行し直すと点数や文言が変わることがある。撮影はこのファイルを使う。

```bash
open docs/demo/index.html
```

Hook の場面（1:28〜1:58 の最後の5秒）は、ターミナルで次を実行して出力を撮る。修正役（`anmoku:flow-fixer`）として起動した Claude Code が設計書を直そうとし、Hook が止めたメッセージと「agent-design_v1.md は元のまま」が出る。最初の行に、実際に実行したコマンドがオプションごと表示される。LLM を使うので30秒ほどかかり、文面は毎回少し変わる。**出力に「[anmoku] 修正役が書けるのは」の行が出た回だけを使う**（出なかった回は撮り直す）。

```bash
CLAUDE_CONFIG_DIR=~/.claude-anmoku CLAUDE_BIN=~/.local/share/anmoku/claude bash scripts/demo_hook.sh
```

固定版は次のコマンドで作った（フローは承認しないので「人の承認待ち」のまま。設計書の評価は修正版フローを物差しにする）。実行し直すと点数や文言が変わるので、撮り直す場合は台本の該当箇所（点数・往復の結果・指摘の順・質問5つ）を画面に合わせて直す。

```bash
uv run anmoku run evals/scenarios/basic --out runs/demo-v3 --fresh \
  --design agent-design_v1.md agent-design_v2.md --test test-spec_v1.md
open runs/demo-v3/index.html
```

- 画面①はページを開き直して、3つの「読み込む」がある状態から撮る。→キーでも1人ずつ進められる
- 「読み込む」は、コマンドで読み込み・分析済みの中身を画面に並べるボタン（押した時点で分析が走るわけではない）
- ブラウザの幅は1500px程度。文字が小さければ拡大（⌘＋）
