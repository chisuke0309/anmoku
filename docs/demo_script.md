## 撮る前の準備

台本は、結果を固定した実行（`docs/demo/index.html`）に合わせて書いている。LLM を使うので、実行し直すと点数や文言が変わることがある。撮影はこのファイルを使う。

```bash
open docs/demo/index.html
```

実行し直して撮る場合は、次で作り直し、台本の該当箇所（点数・呼び方のまとまる人数・往復の結果）を画面に合わせて直す。

```bash
uv run anmoku run evals/scenarios/basic --approve-flow \
  --design agent-design_v1.md agent-design_v2.md --test test-spec_v1.md
open evals/scenarios/basic/anmoku-out/index.html
```

- 画面①は「最初から」を押して0人目に戻してから撮る。→キーでも1人ずつ進められる
- ブラウザの幅は1500px程度。文字が小さければ拡大（⌘＋）
